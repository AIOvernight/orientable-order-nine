# AI use and provenance

Research candidate generation, auditing, formalization, verification code and drafting used AI from the same platform in separate tasks. The independent verifier is independent in implementation. Those tasks do not constitute independent human or institutional peer review.

The release preserves the finite certificates, witness words, connectivity data and Lean proof sources. The mathematical core was copied byte-for-byte from the sealed version-3 review package. [CORE_HASHES.json](../evidence/CORE_HASHES.json) records those files, and [DATA_PROVENANCE.json](../DATA_PROVENANCE.json) records original data hashes and transformations. Private workspace paths have been replaced by descriptions; the mathematical values are unchanged.

The final Lean theorems establish attainment and a universal upper bound. The underlying trusted components are Lean 4.19.0, its standard library, and the interpretation of the definitions as the intended mathematical problem. The Python verifier is not used as a trusted oracle in Lean.

The historical successful run is retained in [evidence/verified-run](../evidence/verified-run). Development failures are not counted as accepted proofs. The public repository does not require private development transcripts or access to the original research environment.

Third-party books and article PDFs are not redistributed. The bibliography links to the sources and identifies the passages examined. This preparation package contains the original exposition and proof artifacts, not the restricted 1993 chapter.
